# Gobinda Jewels website

A responsive, GitHub Pages-ready jewellery storefront inspired by the supplied mobile UI reference. Built with plain HTML, CSS and JavaScript, so no build tools or package installation are needed.

## Preview locally

Open `index.html` in a browser. An internet connection is needed for the Google Fonts and remote product photography.

## Publish on GitHub Pages

1. Create a new repository on GitHub, for example `gobinda-jewels`.
2. Upload all files in this folder (`index.html`, `style.css`, `script.js`, and `README.md`) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. Your public URL will appear in the Pages settings.

## Included

- Responsive desktop and mobile layout
- Category browsing and Women / Men / Kids filters
- Product sorting and show-more control
- Wishlist saved in browser local storage
- Shopping bag with quantity counts and subtotal
- Newsletter demo interaction
- GitHub Pages-compatible static files

## Before accepting real orders

This is a front-end demo. Product names, prices and photography in `script.js` are sample content. Replace them with your actual catalogue. The cart and checkout do not process payments or save orders to a server. Connect a secure backend and payment provider before taking real customer orders. Never put secret API keys in these public files.
